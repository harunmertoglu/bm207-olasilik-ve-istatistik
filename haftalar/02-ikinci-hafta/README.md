# BM207 Olasılık ve İstatistik — 2. Hafta

İkinci hafta notları, el yazısı PDF'nin 14. sayfasındaki “Olasılığın Klasik Tanımı” başlığından 25. sayfaya kadar temize çekilmiştir.

- Düzenlenebilir kaynak: [`src/ikinci-hafta.typ`](./src/ikinci-hafta.typ)
- Şekiller: [`assets/`](./assets/) altındaki SVG dosyaları
- PDF: [`ikinci-hafta.pdf`](./ikinci-hafta.pdf)

PDF'yi proje kökünden yeniden oluşturmak için:

```sh
typst compile --root . haftalar/02-ikinci-hafta/src/ikinci-hafta.typ haftalar/02-ikinci-hafta/ikinci-hafta.pdf
```

Orijinal PDF'nin 15. sayfasında sağ kenardan kesilen kart destesinin örnek uzayı satırı “maça papaz” olarak tamamlanmıştır. 22. sayfadaki geometrik olasılık formülünde ölçü gösterimi `m(A)/m(S)` olarak düzeltilmiş, 23. sayfadaki kaynak sonucu ve not korunmuştur.

Matematiksel gözden geçirmede doğru parçasından üçgen oluşturma koşulları ve taralı bölge, bozuk ürün hesabındaki ikinci çarpım ve kart sorusunun birleşim formülü düzeltilmiştir.
